Panduan & Petunjuk Penggunaan

Navigasi Kanvas

  • Pan (Geser Canvas): Klik dan tahan area kosong di kanvas lalu seret (drag).
  • Zoom (Perbesar/Perkecil): Gunakan scroll mouse atau tombol (+ / −) di pojok kiri bawah.

Mode Aplikasi (View vs Editor)

  • View Mode: Hanya dapat melihat diagram, tracing jalur, dan melakukan simulasi padam.
  • Editor Mode: Menambah node baru, mengedit node, menghapus cabang, serta mengopi/menempel cabang.

Shortcut Keyboard (Khusus Mode Editor)

  • Ctrl + C : Menyalin (copy) node beserta seluruh sub-cabangnya.
  • Ctrl + V : Menempelkan (paste) struktur node ke parent yang dipilih.
  • Delete / Backspace : Menghapus node beserta seluruh cabang turunannya.
